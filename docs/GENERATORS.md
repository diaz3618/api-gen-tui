# Generator Categories

A categorized list of available data generators.

## Security & Authentication

* **Keys & Secrets:** `api-keys`, `encryption-keys`, `laravel-key`, `webhook-secrets`, `ssh-keys`
* **Tokens:** `api-tokens`, `bearer-tokens`, `jwt-tokens`, `oauth-tokens`
* **Passwords:** `passwords`, `passphrases`, `pin-codes`
* **Hashing:** `hashes`, `bcrypt-hashes`, `salts`

## Network & System

* **Identifiers:** `uuids` (v1, v3, v4, v5, v7), `minecraft-uuid`
* **Encoding:** `base64`, `base64-string`
